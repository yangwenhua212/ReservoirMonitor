# 水库水文数据监测可视化系统

## 项目简介
水库水文数据监测可视化系统是一个基于 Flask 的 Web 应用，用于对水库的水位、降雨量、流量等水文数据进行采集、管理、分析和可视化展示。系统支持多水库管理，提供智能预警、统计分析、地理信息展示等功能，适用于水利管理部门进行日常监测与决策支持。

## 技术栈
| 分层 | 技术 | 说明 |
|------|------|------|
| **后端框架** | Python Flask 2.3+ | Web 应用核心框架 |
| **数据库** | MySQL | 数据持久化存储 |

| **数据处理** | Pandas 2.1+ | 数据导入导出（CSV/Excel） |
| **用户认证** | Werkzeug Security | 密码哈希与会话管理 |

## 功能模块
### 1. 用户认证与权限管理
- 用户注册、登录、退出
- 双角色体系：**管理员（admin）** 和 **普通用户（user）**
- 个人资料编辑、密码修改
- 管理员可管理所有用户（增删改查、角色分配、密码重置）

### 2. 水文数据管理（CRUD）
- 录入水位、降雨量、流量等监测数据
- 数据查看与检索（表格展示）
- 数据编辑与删除
- **Excel / CSV 批量导入**（智能列名映射，支持中英文）
- **Excel / CSV 导出**（含数据统计汇总）

### 3. 数据可视化（ECharts）
- 折线图、柱状图展示水位、降雨量、流量趋势
- 支持按水库筛选查看
- 支持选择最近 N 条或最近 N 天数据

### 4. 地理信息展示（Leaflet 地图）
- 基于 Leaflet + 高德地图底图
- 地图上标注水库位置，点击查看详细信息
- 一键跳转至对应水库的图表分析页面

### 5. 智能预警系统
- 添加/编辑/删除预警规则
- 规则参数：水位（water_level）、降雨量（rainfall）、流量（flow_rate）
- 阈值设置：最小值、最大值或范围触发
- 自动检查最新数据并记录预警历史
- 支持预警数据导出为 Excel

### 6. 统计分析报告
- 系统核心指标看板（水库总数、数据总条数、监测天数）
- 水位异常统计
- 近 7 天各水库数据录入活跃度

### 7. 数据库管理（管理员）
- 查看数据库表信息（行数、大小、更新时间）
- 数据库整体统计概览
- 数据库优化（ANALYZE / OPTIMIZE）
